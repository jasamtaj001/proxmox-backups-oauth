Proxmox Backups

Privacy policy

Last updated: 31 October 2026.

Proxmox Backups is a private utility operated by the owner of the Google account that authorizes it. It is designed to store that owner's encrypted backup archives in Google Drive.

Access and use

The application requests the Google Drive drive.file permission. It uses this access to create its backup folder, upload encrypted archives, list and verify its own copies, download them for recovery, and remove older copies under the owner's retention policy. It also reads the account's storage quota to check available capacity.

The app does not request general access to the rest of Google Drive, Gmail, contacts, or calendars. It does not use Google API data for advertising, profiling, sale, or training artificial-intelligence models.

Storage and sharing

Backup contents and filenames are encrypted locally before upload. Google Drive stores the encrypted files and normal service metadata. The owner's encryption settings are kept separately from those cloud archives. OAuth credentials are stored in protected configuration files on the owner's computers to allow unattended transfers.

The application does not share backup data with other users or third parties beyond Google Drive as the selected storage provider. It has no public registration, analytics, or tracking service. The owner remains responsible for any access they separately grant within Google Drive.

Retention, deletion, and control

The owner selects how many verified recovery points to retain. Older app-created copies may be moved to Google Drive Trash, where Google's retention rules apply. Local backups have a separate retention policy.

The owner can stop scheduled uploads, remove the app's files, and revoke its Google Account access. Revoking access does not automatically delete existing encrypted files. Removing encryption settings can make those files unrecoverable, so recovery credentials must be retained securely.

Google API data

Google API data is used only for the backup functions described here. The application follows the Google API Services User Data Policy and its applicable Limited Use requirements.

Contact

For questions or requests, contact the owner of the Google account used to authorize this private application, using the support contact shown on its Google consent screen.
